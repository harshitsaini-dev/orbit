# 2026-08-26

## The delete that hung at zero

Deleting 167 files sat on *"Deleting 0 of 167…"* and never moved. The batching added earlier was
not the problem — 167 was under the old cap too, so this had been broken before that change and
the cap fix had simply not touched it.

Every adapter deleted in a `for` loop: one round trip per file, one after another. From Render in
Singapore to Drive that is roughly a third of a second each, so 167 files is about a minute — and
`api.orbit.harshitsaini.in` is proxied through Cloudflare, **which closes a request after a
hundred seconds**. So it did not fail slowly, it hung: the browser waited on a request that had
already been cut, and nothing was reported either way.

Confirmed rather than guessed — `curl -D -` on the health route shows `Server: cloudflare` and a
`CF-RAY` header in front of `x-render-origin-server`.

**`bulkMap` in `packages/adapters/src/bulk.ts`**, used by all eight adapters. Six at a time, which
turns a minute into seconds. Concurrency is also the risk — too much of it is the fastest way to
be rate-limited on exactly the selection sizes where that hurts — so the limit is deliberately
modest, and yesterday's 403 handling backs off when a provider says to slow down.

A shared cursor rather than fixed slices, because a folder is a subtree and a file is one call.
Equal chunks would leave five workers idle behind whichever one drew the heavy end; there is a
test for that specific case.

Batches dropped from 100 to 50. Fifty at six at a time is a few seconds, which leaves real
headroom under the hundred-second ceiling even when a rate limit is being waited out.

## Progress where the count was chosen

The counter lived inside the confirm dialog, which is the wrong place twice over: it covers the
list it is emptying, and it keeps a modal up for the minutes a large delete takes.

The dialog now closes the moment the work starts — its warning has been read and agreed to — and
a bar appears directly above the select-all row, which is where the number being counted down was
chosen. `aria-live="polite"`: worth announcing, not worth interrupting with on every batch.

**Tests: 984 passing** (9 new on `bulkMap`, including that concurrency is bounded, that one
failure never abandons the rest, and the idle-worker case), plus 21 Playwright specs headed.
