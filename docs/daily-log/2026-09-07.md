# 2026-09-07

## A banner, built from the app's own tokens

`docs/assets/banner.svg`. The colours are read out of `tokens.css` rather than approximated —
`#12151f` page, `#1c1f2b` surface, `#6c8cff` accent, `#98a1b8` muted — and the mark is the same
geometry as `BrandMark.tsx` and the favicon, scaled up, ring passing behind the hub at the top and
in front at the bottom, clipped to the hub's own disc so the two never seam.

SVG rather than PNG: crisp at any width, diffs in git, 7.6 KB.

Three things came out of actually rendering it instead of trusting the markup.

**The chips overlapped.** Their widths were eyeballed. They are now measured in a browser, and
each takes the *widest* result across three font stacks — GitHub will not have Inter, so the
chip has to fit whatever the reader's machine resolves. The row is 779 px in an 794 px space,
checked by an assertion in the generator rather than by eye.

**The file was not valid XML.** The comments named the design tokens, and a token is spelled
`--accent`: **an XML comment may not contain two hyphens in a row.** Browsers render it happily,
strict parsers reject the whole file, and that gap is exactly how a broken banner reaches a README
unnoticed. Caught by `xml.dom.minidom`, and the trap is now written into the file for whoever
edits it next.

**No style block, no CSS variables, no animation.** GitHub sanitises all three. It was also
rendered through a plain `<img>` with a data URI — the strictest path, and the one GitHub
actually uses — rather than only as inline markup where far more is permitted.

README updated alongside it: the banner at the top, bulk actions described as the background jobs
they now are, the Bin's uncapped loading, rate limits, and a sync entry that says plainly the
mirror does not back browsing. Test counts replaced with the real ones — 987 unit and integration,
399 Playwright specs — and the verification table corrected: `npm run build --workspaces` was
listed as clean and does not pass at all, because `@orbit/adapters` has no build script.
