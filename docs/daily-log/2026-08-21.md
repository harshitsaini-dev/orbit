# 2026-08-21

## Built

- Scaffolded the npm-workspaces monorepo: `apps/web`, `apps/server`,
  `packages/shared-types`, `packages/db`, `packages/adapters`.
- Defined the `ProviderAdapter` contract and the normalised `OrbitFile` model — the single
  abstraction the whole aggregator rests on. Added capability flags (`star`, `sharedWithMe`,
  `delta`, `resumableUpload`, `rangeRequests`) so the UI can hide unsupported actions instead
  of surfacing provider-specific failures.
- Wrote the Drizzle/libSQL schema for all ten tables. Same code path targets a local SQLite
  file (local mode) or Turso (hosted mode) via `DATABASE_URL`.
- Added `BaseAdapter` (throws `NotImplementedError` for anything unimplemented, so a
  half-finished adapter can never look healthy) and the six provider stubs plus a registry.
- Stood up the Express app: helmet, CORS pinned to `APP_URL`, cookie-parser, tighter rate limit
  on `/auth` than `/api`, structured 404/500 handlers.
- Attached the WebSocket hub to the same HTTP server and wired node-cron in the same process —
  one Render free service covers API + WS + cron.
- AES-256-GCM helpers for token-at-rest encryption plus a `redact()` log filter.
- Frontend: Vite + React + PWA plugin, Claymorphism token system, three-way theming
  (light/system/dark) with a five-colour accent picker, and the three.js orbiting-spheres hero
  (pauses on tab blur, static frame under `prefers-reduced-motion`).

## Tested

- Adapter contract suite: registry completeness, per-provider id/auth/capability/method checks,
  path normalisation.
- Server: `/health`, `/health/providers` (asserts all six providers), structured 404.
- Playwright smoke suite across desktop/tablet/mobile projects: landing page renders, provider
  list arrives from the API, nav works, theme persists across reload.

## Decisions

- ADR 0001: aggregate-only — Orbit never persists file bytes.
- ADR 0002: libSQL/Turso over a hosted Postgres, so local and hosted modes share one driver.
- ADR 0003: one Node process for API + WebSocket + cron, to fit a single free Render service.
